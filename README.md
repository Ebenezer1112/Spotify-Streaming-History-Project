xx## Spotify-Streaming-History-Project
Spotify User's complete music streaming history data, including timestamps, track, artist, and album names, and reasons for playing and ending each track.

## Project Overview
This project analyzes Spotify streaming history data using Microsoft Excel to uncover listening patterns, user behavior, and music preferences over time. The analysis transforms raw streaming data into meaningful insights through data cleaning, exploratory analysis, Pivot Tables, Pivot Charts, and an interactive dashboard.

## Objective
The project explores key metrics such as total streams, total listening time, most-streamed artists and tracks, listening activity by day and time, and changes in listening behavior over time.
The goal of this project is to demonstrate how Excel can be used to clean, analyze, visualize, and communicate insights from real-world streaming data. The final dashboard provides a clear and interactive view of listening habits and highlights the artists, songs, and periods that contributed most to overall streaming activity.

## Key Areas Of Analysis
1. Total number of streams and listening time
2. Most-streamed artists and tracks
3. Listening trends over time
4. Listening patterns by day and hour
5. Most frequently played songs and artists
6. Skipped and completed tracks
7. Monthly and yearly streaming activity
8. Overall music listening behavior
   
## Tools and Techniques
1. Microsoft Excel
2. Data Cleaning & Transformation
3. Excel Formulas
4. Pivot Tables
5. Pivot Charts
6. Data Visualization
7. Interactive Dashboard
8. KPI Analysis
   
## Project Outcome
The final result is an Excel-based Spotify Streaming Dashboard that converts raw streaming records into easy-to-understand visual insights. This project demonstrates practical skills in data analysis, visualization, dashboard development, and storytelling with data.
